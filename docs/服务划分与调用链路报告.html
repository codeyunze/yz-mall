yz-mall 服务划分与调用链路报告

依据仓库源码与本地配置整理 · 端口以各服务 application.yaml 为准 · 生成日期 2026-10-11 · 工程版本 0.0.8-SNAPSHOT

概述 可运行服务 库模块 网关路由 调用链路 Feign 清单 中间件 分层约定

1. 概述

yz-mall 是基于 Spring Boot 3.4.x + Spring Cloud 2024.x + Spring Cloud Alibaba 的微服务后端。 生产可运行进程包括：网关、系统管理（内嵌认证与流水号）、商品、订单、车辆终端、接入网关； 认证（mall-auth）与业务流水号（mall-serial）以库模块形式嵌入 mall-sys，不单独占端口。

端口说明：下表「本地端口」取自各模块 src/main/resources/application.yaml。 k3s / Nginx 对外暴露端口可能不同（如网关 Service 25001、Nginx 监听 5000 反代到网关 5001）。 精确路由 predicates 在 Nacos gateway.yaml，仓库无完整副本，下表 Path 按 Controller 前缀推断。

5.2 典型业务链路

  • A. 管理端登录
    Browser → Gateway → mall-sys(auth-core) → Redis(验证码/会话) + MySQL(用户角色) → 返回 Token
  • B. 鉴权后业务请求
    Browser + Token → Gateway(checkLogin) → 目标服务 → @SaCheckPermission → Redis 权限缓存 / 业务 DB
  • C. 下单扣库存
    Browser → Gateway → mall-oms → Feign ExtendPmsStock* → mall-pms(extend/pms/stock) → 库存落库；流水号 Feign → mall-sys(extend/serial)
  • D. 车机遥测上报
    车机 MQTT → EMQX → mall-tw-access(Paho/桥接) → Kafka(tw-telemetry-raw) → mall-tw 消费 → Redis/MySQL 最新点 + ClickHouse 轨迹
  • E. EMQX 设备鉴权
    EMQX HTTP Auth → mall-tw-access:/emqx/auth → Feign mall-tw:/extend/tw/device/verify（dev-bypass 时可跳过）

7. 中间件与基础设施

注册与配置

  • Nacos Discovery + Config（:8848）
  • Namespace：ff6944dd-b11f-4403-8245-6c621b2f54c8
  • 公共 data-id：middleware.yaml、sa-token.yaml；网关另拉 gateway.yaml

数据与缓存

  • MySQL：sys / pms / oms / tw
  • Redis / Redisson：会话、权限、在线 VIN、防重、锁
  • ClickHouse：tw GPS 轨迹
  • 对象存储（RustFS/Qof）：文件能力经 sys

消息

  • RocketMQ：sys / pms / oms / tw 业务异步
  • Kafka：网关访问日志；tw-access → tw 遥测原始 GPS
  • MQTT（EMQX）：车机上下行，由 access 接入

可观测与调度

  • Actuator + Prometheus metrics
  • XXL-JOB：sys / pms 执行器
  • SkyWalking / ELK：按环境启用
